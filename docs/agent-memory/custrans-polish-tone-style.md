Albert（JQ Industries）给客户的英文草稿润色，需学习并保持以下**语气风格 / 说话态度 / 说话角度**（样本：回访老客户 + 推介新产品 Tactile Body Suit）。

**① 说话角度（perspective）**
- Albert 给的英文草稿 = **外发邮件**，视角是 **JQ 卖方**对客户做**主动回访**，再自然**引出新产品**（交叉销售 / 顺势推介）。
- 人称切换规律：**个人跟进用 I**（I wanted to follow up / I have attached），**公司/产品用 We**（We have recently developed）。
- 出发点始终是「关心客户使用体验」（先问用得好不好），不是单纯推销。

**② 说话态度（attitude）**
- 主动、真诚、不施压。
- 开场先寒暄关心：`I hope you have been well. It has been a while since we last spoke.`
- 用**开放式问句**回访，展现关注而非索取：`How has it been performing so far? Has everything been working as expected?`
- 介绍新产品**自信但克制**（用 `It is designed to...` 说清价值），不硬销。
- 结尾留开放邀请，把决定权交给对方：`Please feel free to contact me if you need any additional information or support.`

**③ 语气风格（tone / style）**
- 温暖专业的商务英语：老客户亲切不随意，新客户正式但友好。
- 邮件结构固定：问候 → 目的 → 询问/说明 → 附件 → 开放结尾 → Albert 双语签名（见 CONVENTIONS.md §3）。

**核心句式映射（重点沉淀）**
| 原草稿 | 润色后（目标风格） |
|---|---|
| Long time no see! | I hope you have been well. It has been a while since we last spoke. |
| How would the tactile glove work for this 5 month test? Is everything as expected? | I wanted to follow up on the tactile glove during the five-month test period. How has it been performing so far? Has everything been working as expected? |
| cover the whole body and make the force collection | cover a larger area of the body and capture distributed pressure/force data |
| in attach | I have attached ... for your reference |
| pls cotect me | Please feel free to contact me if you need any additional information or support. |

**Why:** Albert 明确要求学习这套语气/态度/角度；此前 AI 曾把 Albert 的草稿误判为「客户来信」，方向错误。固化后保证后续润色风格一致、方向正确。
**How to apply:** 每次润色 Albert 的英文草稿时，先按上面的「三个维度 + 句式映射」改写，落 Albert 双语签名，再走 CONVENTIONS.md §2 逆向翻译核查。参见 [[custrans-working-conventions]]。
